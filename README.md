# Machine Learning: Theory to Code

**Understanding Machine Learning, one concept at a time.**

Machine Learning can feel complicated when you're just starting, especially when you're trying to connect the theory, mathematics, and actual code.

While learning ML, I started documenting concepts in my handwritten notes, along with examples and implementations. Now, I'm turning those notes into a series of Jupyter notebooks to share what I've learned.

The goal is simple: **Understand the concept, see how it works, and implement it yourself.**

## What You'll Find Here

- 💡 **Simple explanations** — understand what a concept means and why we need it.
- 📐 **Mathematical intuition** — learn the reasoning behind algorithms.
- 💻 **Python implementations** — follow the code, experiment, and learn by doing.
- 📊 **Diagrams and visualizations** — understand concepts visually.
- 🧪 **Practical examples** — connect theory with real-world applications.

The notebooks follow a beginner-friendly progression, starting with ML fundamentals and gradually moving toward more advanced topics.

1. Open a notebook directly on GitHub to read its explanations and view saved outputs.
2. Download the notebook or open it in Jupyter or VS Code to run the code yourself.
3. Experiment with the examples and try changing the inputs to see what happens.

Some notebooks may require additional Python libraries or datasets. Relevant setup instructions will be included where needed.
